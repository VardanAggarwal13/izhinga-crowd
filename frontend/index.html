API Credentials *
Every real endpoint now requires authentication. Get a client_id/client_secret pair by running npm run create:client "your-team-name" on the backend. This form fetches a token automatically on first submit and reuses/refreshes it — you don't need to call the token endpoint yourself.

Holiday / Festival
Leave as "None" and today's actual holiday/festival (if any) is looked up from our own database for this POI's city — you almost never need to pick one yourself. Pick a specific type only to override.
Event at / near this POI
Leave as "None" and today's actual event (if any) is looked up from our own database — same auto-detection as Holiday above. Pick a specific type only to override.
Weather
Leave as "Auto-detect" and current weather is pulled live from Google Weather for this POI's real coordinates. Pick a specific type only to override or to test without a Google Weather API key configured.
